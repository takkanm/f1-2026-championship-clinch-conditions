# F1 2026 ドライバーズチャンピオン 最短確定条件

2026-10-11 シンガポールGP終了時点のランキングから、各ドライバーが年間チャンピオンを確定させるための
「最短条件」を計算する Ruby プログラムです。

## 必要環境

- Ruby 3.3 以上（標準ライブラリのみ。動作確認は Ruby 4.0.1）
- テストは minitest（Ruby に同梱）

## 実行方法

```bash
bin/clinch
```

`data/season.yml` を読み込み、`output/report.md`（日本語レポート）と `output/result.json`（機械可読版）を生成し、
標準出力に要約を表示します。入力・出力先は引数で変更できます。

```bash
bin/clinch data/season.yml output
```

テスト:

```bash
ruby -Itest -e 'Dir["./test/*_test.rb"].sort.each { |f| require f }'
```

（総当たり検証を含むため 1 分弱かかります）

## 定義

- **N** = 残りレース数（6）。**k戦後** = 残りレースのうち k 戦目終了時点。
- **k戦後に確定**: 残り N−k 戦がどんな結果でも、他の全ドライバーに逆転されない状態。ライバル R ごとに次のいずれか:
  - 自分の点 > R の点 + 25×(N−k)
  - 上式が等号で、かつ 自分の優勝数 > R の優勝数 + (N−k)
- **可能性あり**: 現在の点 + 25×N が首位の現在の点以上（同点は優勝数で判定。優勝数も同じ場合は未確定なので可能性ありに残す）。
- **同点処理**: 同点なら優勝数の多い方が上位。優勝数も同じなら 2 位回数以下の比較になるがデータが無いため「未確定」とし、確定とはみなさない。

## 計算方法

可能性ありの各ドライバー D について:

1. **最短確定レース k\***: D が全勝しライバル全員 0 点という最良ケースで確定できる最小の k。
2. **条件の列挙**: D の k\* 戦分の着順（P1〜P10・圏外の 11 通り）を重複組合せで全列挙し、各パターンについて
   各ライバルが k\* 戦で獲得してよい最大累計点を求める。
   - 同じレースで 2 人が同じ順位は取れないため、D が優勝したレースではライバルの最大は 18 点として物理上限を計算する。
     上限まで取っても確定する場合は「制限なし」。
   - 同点でも優勝数で上回れる場合は 1 点緩む（ライバルの k\* 戦中の優勝数に条件が付く場合はそれも出力）。
   - D の獲得点ごとにまとめ、他のパターンに支配される（全ライバルの許容が同等以下の）パターンを除いたパレート最適な条件だけ残す。
3. **出力**: 最短確定レース名、確定に必要な D の最小獲得点と着順例、D が全勝した場合に各ライバルへ許される最大獲得点、条件表。
4. **首位ドライバー**については、次戦で確定するための「自分の着順 × 各ライバルの許容着順」の表も出力する。

確定条件はライバルごとの条件の AND に分解できるため、条件は各ライバル独立の上限として表しています
（ライバル同士の着順の衝突は条件を緩める方向にしか働きません）。

## テスト

- ポイント計算、可能性判定、確定判定、同点処理の単体テスト
- 検算値（可能性ありの 6 人、Antonelli の最短確定と点差条件、6 戦全勝時の許容点）との突き合わせ
- 総当たり検証（定義どおりの判定 = 条件式による判定）
  - k=1: 可能性ありの 6 人の着順を全列挙（424,051 通り）
  - k=2: 6 人同時の全列挙は約 1.8×10^11 通りで現実的でないため、(D, ライバル) の全 30 ペアについて 2 戦分を全列挙（各 12,321 通り）し、
    さらに 6 人同時のランダム標本 55,000 通り（固定シード）で確認
