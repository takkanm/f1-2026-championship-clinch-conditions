# 環境
- Ruby 3.3以上、標準ライブラリのみ（テストは minitest）。Rubyが無ければ mise 等で導入
- 構成:
  - data/season.yml … 上記の事前条件をすべてデータ化（コードにハードコードしない）
  - lib/ … 計算ロジック
  - bin/clinch … 実行エントリポイント
  - test/ … テスト
  - output/report.md, output/result.json … 実行結果
  - README.md … 実行方法と定義の説明

# 用語の定義
- N = 残りレース数(6)。k戦後 = 残りレースのうちk戦目終了時点
- 「k戦後に確定」= k戦後の時点で、残り N-k 戦がどんな結果でも、他の全ドライバーに
  逆転されない状態。ライバルRごとに次のいずれかを満たすこと
  - 自分の点 > Rの点 + 25×(N-k)
  - 上式が等号で、かつ 自分の優勝数 > Rの優勝数 + (N-k)
- 「可能性あり」= 現在の点 + 25×N が首位の現在の点以上（同点は優勝数で判定）

# 計算内容
可能性ありの各ドライバーDについて:
1. 最短確定レース k*: 確定を満たす結果が存在する最小のk
   （Dが全勝・ライバル全員0点が最良ケース）
2. k* における条件の列挙:
   - Dのk*戦分の着順パターンを重複組合せで全列挙（1戦11通り: P1〜P10, 圏外）
   - 各パターンについて、各ライバルがk*戦で獲得してよい最大累計点を計算
   - 同じレースで2人が同じ順位を取れない制約を考慮する
     （例: Dが優勝したレースではライバルの最大は18点）
   - Dの獲得点ごとにまとめ、支配されるパターンを除いたパレート最適な条件だけ残す
3. 最短条件として次を出力:
   - 最短確定レース名
   - 確定に必要なDの最小獲得点と、その着順例
   - Dが全勝した場合に各ライバルへ許される最大獲得点
4. 首位のドライバーについては、次戦で確定するための条件を
   「自分の着順 × 各ライバルの許容着順」の表でも出力

# 出力
- output/report.md: 日本語。ドライバーごとの見出し、最短確定レース、条件表、
  可能性なしのドライバー一覧、採用した仮定
- output/result.json: 同じ内容の機械可読版
- 標準出力に要約

# テスト（minitest）
- ポイント計算、可能性判定、確定判定、同点処理の単体テスト
- 総当たり検証: k=1 と k=2 について、可能性ありの6人の着順を全列挙し、
  定義どおりの判定と条件式による判定が一致すること
- 検算値（手計算。食い違ったら原因を調べ、どちらが正しいか報告する）:
  - 可能性あり: Antonelli, Russell, Hamilton, Verstappen, Leclerc, Norris の6人
  - Antonelli の最短確定はオースティン。条件は「Antonelliの獲得点 − ライバルの獲得点」が
    Russell 24以上, Hamilton 15以上, Verstappen 7以上, Leclerc 1以上, Norris −13以上
    （同点時の優勝数判定で1点緩む場合あり）
  - 他5人の最短確定は最終戦アブダビ
  - 6戦全勝時、Antonelliに許される6戦合計の最大点（同点を除く）:
    Russell 47, Hamilton 38, Verstappen 30, Leclerc 24, Norris 10

# 進め方
1. 環境を作り、data/season.yml を作成
2. 実装とテストを書き、テストをすべて通す
3. bin/clinch を実行して output/ を生成
4. report.md の要約、検算値との一致状況、採用した仮定を最後に報告
